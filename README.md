# Calculadora de Impuestos en Python

## Descripción

Este proyecto consiste en una calculadora de impuestos desarrollada en Python. Permite calcular el precio final de un producto a partir de su precio original y un porcentaje de impuesto ingresado por el usuario.

El programa también valida que el precio no sea negativo y que el porcentaje de impuesto se encuentre entre 0 y 100.

## Funcionalidades

- Solicita el precio de un producto.
- Solicita el porcentaje de impuesto.
- Calcula el impuesto correspondiente.
- Calcula el precio final.
- Valida entradas inválidas.
- Permite realizar varios cálculos durante la misma ejecución.

## Conceptos aplicados

- Variables
- Entrada de datos (`input`)
- Conversión de datos (`float`)
- Condicionales (`if` / `else`)
- Ciclos (`while`)
- Operadores lógicos (`or`)
- Formato de cadenas (`f-strings`)
- Redondeo con `round()`

## Tecnologías

- Python 3

## Cómo ejecutar

1. Clona el repositorio.
2. Abre una terminal en la carpeta del proyecto.
3. Ejecuta:

```bash
python calculadora_impuestos.py
```
